# GrindURUS documentation

**Automated market taking** — infrastructure that turns price volatility into yield.

GrindURUS runs a dual-sided strategy on crypto pairs: buy low / sell high and sell high / buy low. You do not need to predict direction. Holders who do not trade get the same harvest through **GRAI**, a dollar book-priced fund share.
