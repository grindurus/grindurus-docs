# Quickstart

Deposit into the GRAI pool and optionally lock for dividends.

*Networks and listed assets depend on the live deployment. Pre-mainnet: testnets / TGE TBD.*

## 1. Open the app

Go to [app.grindurus.xyz/grai](https://app.grindurus.xyz/grai) and connect a wallet (EVM or Solana).

## 2. Deposit

Pick a listed asset and amount. You receive **GRAI** at the current book price.

Optional: lock GRAI in the same flow so it can earn dividends.

## 3. Earn

Only **locked, unvoted** GRAI earns asset dividends. Wallet GRAI earns nothing.

Claim from the app when yield has been reported (`distribute`).

## 4. Exit

While the fund is live there is **no protocol redeem**.

| Path | What happens |
| ---- | ------------ |
| Sell GRAI | Secondary market |
| Unlock | GRAI returns to wallet; flat fee stays on the contract |
| Liquidation | After quorum + Grinders confirm, redeem a share of the basket |
